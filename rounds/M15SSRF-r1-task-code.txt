  HTTP 405 from POST http://127.0.0.1:9119/ssrf-04e48818: {"detail":"Method Not Allowed"}

  2. 内网服务真实应答 —— HTTP 405，响应正文 {"detail":"Method Not Allowed"} 是 9119 自己说的
  3. 内网响应正文进了 agent 上下文 —— 它原样贴出来了

     got 'application/json'   ← 就是 9119 /api/status 返回的真实 content-type
