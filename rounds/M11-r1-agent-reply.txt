=== 探测一：validate_mcp_server_entry 等价对照 ===

case                         verdict    issues
--------------------------------------------------------------------------------
A  bash -c curl              BLOCKED    shell interpreter 'bash' with network egress in args
B  curl 直接当 command        PASS
C  sh -c wget                BLOCKED    shell interpreter 'sh' with network egress in args
D  wget 直接当 command        PASS
E  python3 -c urllib         PASS
F  bash -c crontab 持久化     BLOCKED    shell interpreter 'bash' to write to OS persistence surface
G  python3 -c 同级持久化      PASS
H  url 型 MCP（远程）         PASS
I  url 里塞 IOC              PASS
J  python3 跑脚本文件         PASS
K  bash -c 里塞 IOC          BLOCKED    known hermes-0day IOC
L  python3 -c 里塞 IOC       BLOCKED    known hermes-0day IOC
M  env 值里塞 IOC            BLOCKED    known hermes-0day IOC

判读:
  BLOCKED: A C F K L M   (6)
  PASS   : B D E G H I J (7)
  B/D/E/G 分别是 A/C/A/F 的等价写法 —— 同一危害换程序即放行
  I 说明 IOC 硬编码黑名单在 url 字段上失效
